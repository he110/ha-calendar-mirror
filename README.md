# Calendar Mirror для Home Assistant

Синхронизирует **любой** календарь Home Assistant с календарём в Яндексе, чтобы Алиса
знала о ваших событиях: «Алиса, какие события сегодня?».

Источник — любая сущность `calendar.*`: iCloud (CalDAV), Google, Exchange/ICS
(`remote_calendar`), Todoist и т.д. Интеграцию не интересует, откуда пришли события: она читает их
через HA. Цель — календарь в Яндекс Календаре (подойдёт и любой другой CalDAV-сервер).

## Что делает

- Раз в N минут (по умолчанию 10) сверяет окно «с начала сегодняшнего дня на 30 дней вперёд»
  и приводит целевой календарь к состоянию источника: создаёт, обновляет, удаляет.
- Повторяющиеся события кладёт отдельными вхождениями; перенос одного вхождения
  обновляет событие на месте.
- Трогает **только свои** события (UID с префиксом `ha-mirror-<пара>-`). То, что вы
  или Алиса добавили в целевой календарь руками, не трогает.
- Синхронизация односторонняя: правки копий в целевом календаре перезаписываются.

Чего интеграция **не** делает: не напоминает о событиях и не шлёт уведомления. Если они
нужны, соберите их обычной автоматизацией HA на calendar-триггере.

## Сущности на каждую пару

| Сущность | Что это |
|---|---|
| `switch.calendar_mirror_<id>` | Вкл/выкл синхронизации. Состояние переживает рестарт. |
| `sensor.calendar_mirror_<id>_status` | `ok` / `error` / `disabled` / `suspicious_empty` / `pending`, детали в атрибутах |
| `button.calendar_mirror_<id>_sync_now` | Синхронизировать сейчас |

## Надёжность

- Источник упал или недоступен → цикл пропускается, в целевой календарь ничего не пишется.
- Источник вернул 0 событий, а в цели есть ≥ 3 наших → удаления откладываются
  (статус `suspicious_empty`), пока пустота не продержится 3 цикла подряд.
- Запись идёт последовательно, с паузой, не больше 50 операций за цикл: Яндекс
  ограничивает запись по CalDAV. На 429/5xx цикл прерывается, следующий догоняет.
- Пароль перестал подходить → HA предложит ввести новый (reauth).

## Установка

1. HACS → ⋮ → Custom repositories → `https://github.com/he110/ha-calendar-mirror`,
   категория **Integration** → установить → перезапустить HA.
2. Создать пароль приложения: Яндекс ID → Безопасность → **Пароли приложений** →
   «Календарь». Новый пароль может заработать не сразу.
3. Настройки → Устройства и службы → Добавить интеграцию → **Calendar Mirror**:
   адрес `https://caldav.yandex.ru/`, логин — адрес Яндекс-почты, пароль приложения.
4. В карточке интеграции → **Добавить пару**: источник, целевой календарь, короткий id.
5. Дать Алисе доступ к целевому календарю: приложение «Дом с Алисой» →
   Продуктивность → Календарь → Яндекс Календарь → выбрать календари.

Совет: заведите в Яндексе отдельный календарь под каждый источник — так проще
понимать, откуда событие, и отключать ненужные уведомления Яндекса.

## Совместимость

Проверено на Home Assistant 2026.2 и 2026.9. Нужны config subentries.
